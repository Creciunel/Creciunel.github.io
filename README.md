# Personal CV page

This represint a overview of my academic and professional background, including my education, research interests, publications, and affiliations. The page is designed to provide a comprehensive summary of my qualifications and achievements in the field of computer science, with a focus on my expertise in electrospinning technique, semiconductor materials, embedded systems, microelectronics, and nanotechnology.

## Tehnologies and tools

- Hugo: A static site generator used to build the website.
- Markdown: A lightweight markup language used for formatting text on the website.
- YAML: A human-readable data serialization format used for configuration and data files.
- Git: A version control system used to manage changes to the website's code and content.
- GitHub: A web-based platform for hosting and collaborating on code repositories, used to host the website's source code and manage contributions.
- Visual Studio Code: A code editor used for writing and editing the website's code and content.
- Netlify: A cloud-based platform used for deploying and hosting the website.
- Academic CV Theme: A Hugo theme designed for creating academic CVs and personal websites, used as the basis for the website's design and structure.
