# Smart Inventory Platform with 1D/2D Scanner

### ICNBME 2025 · Springer Proceedings  
Cătălin Creciunel

---

## Problem Statement

- **Manual tracking errors** in healthcare & labs
- **Missing or expired items** reduce efficiency  
- **Lack of real-time visibility** into inventory
- **Inefficient workflows** increase operational risks

---

## Proposed Solution

**Smart Inventory Platform** with:
- IoT scanner device (ESP8266 + GM65)
- Edge computing terminal (Raspberry Pi)
- Centralized management platform

**Key Goals:**
- Automate tracking | Real-time monitoring | Reduce errors | Scalable

## Embedded Scanner Hardware

**Components:**
- ESP8266 microcontroller
- GM65 barcode/QR scanner  
- WiFi + battery powered

**Features:**
- 1D/2D code scanning
- Wireless transmission
- Low power operation

**Stack:** Web CMS + Database + REST API + Mobile Interface

- Inventory management

- Real-time analytics & reporting
- Scalable cloud integration
